# Pioneer 8701 Custom Launcher

Готовий Android-проєкт для збірки APK без встановлення Android Studio (через GitHub Actions).

## Як зібрати APK онлайн за 3 хвилини:
1. Створіть новий репозиторій на [GitHub](https://github.com/new) (можна приватний або публічний).
2. Розпакуйте цей архів та завантажте **всі файли та папки** (включно з прихованою папкою `.github`) у корінь репозиторію.
3. Перейдіть на вкладку **Actions** у вашому репозиторії на GitHub.
4. Дочекайтеся завершення workflow **Build Debug APK** (зелена галочка).
5. Відкрийте завершений запуск, прокрутіть вниз до розділу **Artifacts** та завантажте `pioneer-launcher-apk` (усередині буде файл `app-debug.apk`).
